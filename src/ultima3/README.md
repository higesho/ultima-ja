# ウルティマIII 日本語化の組み立て（DOS 版）

GOG 版ウルティマIII（DOS）を日本語にするための Python の道具です。ゲームのファイルは書き換えず、常駐プログラム U3JP.COM が読み込み直後のメモリを書き換えます。

- `tools/list_en.py <ゲームのフォルダ>` … 訳す英文の一覧を作る
- `tools/build_u3jp.py <ゲームのフォルダ> <訳のファイル> <出力 U3JP.COM>` … 常駐プログラムを作る
- `tools/make_dist.py <ゲームのフォルダ> <U3JP.COM> <説明書の元> <dist フォルダ>` … 配布物をまとめる
- `tools/u3data.py` … 文字列と参照元を集める共通部品
- そのほかは解析・試験用の道具です

必要なもの: Python 3、GOG 版のゲームのファイル、訳の表、美咲フォント。これらはここには入っていないので各自用意してください。
