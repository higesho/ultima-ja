# ウルティマII 日本語化の組み立て

GOG 版ウルティマII（DOS）を日本語にするための Python の道具です。ゲームのファイルは書き換えず、常駐プログラム U2JP.COM が起動後のメモリと会話ファイルを差し替えます。

- `tools/make_ja.py` … 英文と訳の対応表から、位置ごとの訳のファイルを作る
- `tools/build_u2jp.py <ULTIMAII.EXE> <訳のファイル> <出力 U2JP.COM>` … 常駐プログラムを作る
- `tools/make_dist.py` … 配布物をまとめる（窓の表示の DLL は ultima1 の `gl/` で作る）
- そのほかは解析・試験用の道具です

必要なもの: Python 3、GOG 版のゲームのファイル、訳の表、美咲フォント。これらはここには入っていないので各自用意してください。
