Ultima IX: Ascension

ウルティマIX を日本語で遊ぶ

ウルティマIX には、2000年に発売された公式の日本語版があります。 その日本語の文章・音声・ムービーは、海外のファンが作った道具「Pix's Ultima Patcher」の言語パックとして公開されていて、Steam 版や GOG.com 版の英語版に入れると日本語で遊べます。 このページでは、その入れ方と、ほかのファンが作った修正パッチを紹介します。 どれも、このプロジェクトが作ったものではありません。

Pix's Ultima Patcher（GitHub） Steam のストア GOG.com のストア

どんなゲーム？

ウルティマIX は、1999年に発表されたウルティマ シリーズの最終作です。シリーズで初めて、世界のすべてが 3D で描かれています。

地球で暮らすアバタールのもとに、ふたたびブリタニアからの呼び声が届きます。 ガーディアンはブリタニアの各地に巨大な柱を打ち込み、徳の祠は汚され、人々の心は徳から離れつつありました。 アバタールは祠を一つずつ清め、ガーディアンとの最後の戦いに向かいます。

日本語版は、2000年にエレクトロニック・アーツ・スクウェアから発売されました。会話や本だけでなく、登場人物の声もすべて日本語です。

公式の日本語版を入れる

Pix's Ultima Patcher の日本語の言語パック（約300MB）には、次のものが入っています。

  • 会話・字幕・本・物の名前などの日本語の文章
  • 日本語の音声
  • 日本語版のムービー
  • 英語版の u9.exe を、日本語を表示できる日本語版の EXE（u9.jp.exe）に作り変える差分

Steam 版と GOG.com 版の Ultima IX: Ascension で使えます。 入れるとゲームのファイルが上書きされるので、心配なときは先にゲームのフォルダを丸ごと別の場所へ写しておいてください。

言語パックはこのプロジェクトのものではなく、配布がいつまで続くかは分かりません。遊ぶ予定があるなら、早めに入れておくことをおすすめします。

入れ方

  1. GitHub のリリースのページから UltimaPatcher.zip をダウンロードして、好きな場所に展開します。展開したフォルダは、英語に戻すときに使うので残しておきます。
  2. UltimaPatcher.exe を起動して、「Ultima 9」のボタンを押します。
  3. 「Change Game Directory」を押して、ゲームのフォルダ（u9.exe があるフォルダ）を選びます。 Steam 版なら、ライブラリでゲームを右クリックして「管理」→「ローカルファイルを閲覧」で開くフォルダです（多くの場合 C:\Program Files (x86)\Steam\steamapps\common\Ultima IX）。
  4. 「Language」の欄で Jp を選び、「Download」を押します。ダウンロードが終わるまで待ちます。
  5. 「Text:」の「Install」を押すと、文章が日本語になり、u9.jp.exe が作られます。 Windows の日本語の言語パックが要るという英語の案内が出ますが、日本語の Windows ならそのまま閉じてかまいません。
  6. 音声とムービーも日本語にするときは、「Speech:」の「Install」を押します。

起動のしかた

Pix's Ultima Patcher は、日本語以外の Windows でも動くように、u9.exe を Locale Emulator の起動用のファイルに置き換えます。 そのため、このままでは Steam や GOG Galaxy の「プレイ」から起動できません。日本語の Windows では Locale Emulator は要らないので、次のどちらかで起動します。

  • ゲームのフォルダの u9.jp.exe をダブルクリックして起動します。よく遊ぶなら、デスクトップにショートカットを作っておくと便利です。
  • Steam や GOG Galaxy の「プレイ」から起動したいときは、u9.jp.exe をコピーして、同じフォルダの u9.exe に上書きします。

日本語以外の Windows では、Locale Emulator で日本語（ja-JP）の環境として u9.jp.exe を起動します。

Pix's Ultima Patcher を使わずに入れる

Pix's Ultima Patcher が動かないときは、同じものを手で入れられます。

  1. 日本語の言語パック Jp.zip（約300MB）をダウンロードして展開します。
  2. 中の Jp フォルダにある static・sound・Movies の3つのフォルダを、ゲームのフォルダに上書きで写します（音声とムービーが要らなければ static だけでかまいません）。
  3. Pix's Ultima Patcher の GitHub の U9JPLanguagePatch フォルダから u9.exe.octodiff をダウンロードして、ゲームのフォルダに置きます。
  4. 差分を当てる道具 Octodiff で、ゲームのフォルダで次のように実行すると u9.jp.exe ができます。
    Octodiff.exe patch u9.exe u9.exe.octodiff u9.jp.exe
  5. u9.jp.exe をダブルクリックして起動します。

差分は Steam 版・GOG.com 版の元の u9.exe に当てるためのものです。ほかのパッチで u9.exe を書き換えた後では作れません。

英語に戻すには

  • Steam 版: ライブラリでゲームを右クリックして「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を選ぶと、上書きされたファイルが英語版に戻ります。残った u9.jp.exe は消してかまいません。
  • GOG.com 版: GOG Galaxy でゲームの設定（歯車のボタン）から「Manage installation」→「Verify / Repair」を選びます。
  • Pix's Ultima Patcher からは、「Language」で En を選んで「Download」し、「Text:」と「Speech:」の「Install」を押すと英語に戻ります。

Steam の整合性の確認をすると、日本語も消えます。日本語で遊び続けるときは使わないでください。

ファンが作った修正パッチ

ウルティマIX は、発売後の公式パッチでも直しきれなかった不具合が多く残っています。海外のファンが作った修正パッチを紹介します。 どれも Pix's Ultima Patcher の「Ultima 9」の画面から入れられます。

Forgotten World パッチ 1.19H

ファンのチーム Forgotten World による修正パッチです。Pix's Ultima Patcher では「Forgotten World (1.19H)」の欄の「Install」で入ります。

  • 祠を清めた後に、Minoc・Valoria・Skara Brae の町の曲が明るい曲に変わらない不具合を直します。
  • 清めた祠のルーンとシジルが宙に浮いて取れなくなる不具合を直します。
  • 祠を清めた後に、仲間の Mariah と Jaana が町に戻ってくるようになります。
  • Moonglow の地下墓所に何度でも入れるようになるなど、細かな不具合も直します。

日本語版と重なるファイルはないので、日本語版と一緒に入れられます。 直る内容の多くは、新しく始めたゲームでだけ効きます。

詳しくは Forgotten World のサイトと、Ultima Codex の説明（英語）をご覧ください。 Forgotten World のサイトには、ゲームが落ちにくくなる設定の紹介もあります。

Beautiful Britannia R3

Forgotten World による、ゲームの絵（テクスチャ）を細かく描き直すパックです。Pix's Ultima Patcher の「Beautiful Britannia R3」の欄から入れられます。 くわしくは Forgotten World のダウンロードのページをご覧ください。

Dialogue Patch と Economy/Monster Patch（Fan Patch 1.60）

英語の会話の誤りを直すパッチと、店の値段や敵の強さを整えるパッチです。 どちらも英語の文章のファイルを置き換えるので、日本語版と一緒に入れると、会話や本が英語に戻ってしまいます。日本語で遊ぶときは入れないでください。 内容は Ultima Codex の Dialogue Patch と Economy and Monster Patch の説明（英語）をご覧ください。

遊ぶときの注意

  • 日本語版を入れるときは、ほかのパッチより先に入れてください。Pix's Ultima Patcher の「Turn On Fog」のように u9.exe を書き換える機能を先に使うと、u9.jp.exe を作れなくなります。
  • 画面の大きさなどは、Pix's Ultima Patcher の「Graphics Settings」の欄か、ゲームのフォルダの ConfigINI.exe で変えられます。
  • 操作は英語版と同じです。キーの割り当ては、ゲームのフォルダの Default.kmp に書かれています。
