Ultima VII: The Black Gate ＋ The Forge of Virtue

ウルティマVII 日本語化パッチ

GOG.com 版の「Ultima VII: The Black Gate」（拡張シナリオ「The Forge of Virtue」入り）を日本語で遊べるようにする、非公式のファンメイドパッチです。 ウルティマVII を今の Windows で遊ぶためのエンジン「Exult」に日本語の表示を加え、オープニングのガーディアンの語りから、ブリタニアの人々との会話、本や手紙、看板、物の名前、ゲームのメニュー、エンディングまで、ゲームの中の文章を日本語にしています。 フォルダをひとつゲームのフォルダに入れるだけで遊べて、消せば元どおりです。

ダウンロード（GitHub）

どんなゲーム？

ウルティマVII は、1992年に発表されたウルティマ シリーズの第7作です。

前作から、ブリタニアの暦で200年。アバターは、自宅のコンピュータの画面に現れた「ガーディアン」と名乗る赤い顔の存在に呼ばれ、ふたたびブリタニアへ向かいます。 降り立った町トリンシックでは、鍛冶屋とガーゴイルが惨殺されるという奇妙な事件が起きたばかりでした。 旧友イオロとともに事件を追ううち、人々の間に広まる団体「フェローシップ」と、ブリタニアに迫る大きな企みが見えてきます。

町の人々はそれぞれの暮らしを送っていて、マウスで物を手に取ったり、料理を作ったり、パンを焼いたりと、世界の中のほとんどの物に触れられます。 「The Forge of Virtue」は、海に現れた火の島を舞台にした拡張シナリオで、ゲームの途中から遊べます。

入れ方

  1. ダウンロードした Ultima7_JP.zip を展開します。
  2. 出てきた Ultima7_JP フォルダを、フォルダごとゲームのフォルダ（U7.EXE と STATIC フォルダがあるフォルダ）に入れます。
  3. Ultima7_JP フォルダの中の Ultima7_JP.bat をダブルクリックすると始まります。

GOG.com の「Ultima 7 Complete」の The Black Gate で使えます。 ゲームのファイルは書き換えません。設定とセーブデータは Ultima7_JP フォルダの中に作られます。

効果音を鳴らすには

音楽と声は、そのままで鳴ります。効果音は Exult では別に配られているので、鳴らしたいときは次のようにして入れてください。

  1. Exult のサイトのダウンロードのページ（https://exult.info/download.html）を開きます。
  2. 「Single Audio Data packs」の欄にある「Sound pack for Black Gate」（jmsfx.zip）をダウンロードします。Roland MT-32 の音が好みなら「Sound pack for Black Gate (Roland MT-32)」（sqsfxbg.zip）を選びます。両方入れてもかまいません。
  3. ダウンロードした zip の中身を、Ultima7_JP フォルダの中の data フォルダに展開します。
  4. 次に起動したときから効果音が鳴ります。両方入れたときは Roland MT-32 の音が使われ、ESC キーで出るメニューの「音の設定」で切り替えられます。

同じページの「All-In-One Audio Data packs」（exult_audio.zip）には、効果音のほかに音楽を録音したものも入っています。こちらを入れるときも、中身を data フォルダに展開します。

外し方

  • Ultima7_JP フォルダを消します。
  • セーブデータ（Ultima7_JP\save）も一緒に消えるので、残したいときは先に別の場所へ写してください。

遊ぶときの注意

  • GOG Galaxy やいつものショートカットから起動する DOS 版は英語のままです。日本語で遊ぶときは Ultima7_JP.bat から起動してください。
  • セーブデータは DOS 版とは別です。
  • 会話は、画面に出る話題をマウスで選んで進めます。ESC キーで会話を終えます。
  • 主人公の名前は英字で入力します。
  • 呪文の唱え言葉は、原作の言葉をローマ字で表示します。
  • タイトルのロゴや、絵の中に描かれている英字（持ち物の重さの表示など）は英語のままです。
  • Alt＋Enter で全画面と窓を切り替えられます。そのほかの設定は、ESC キーで出るメニューから変えられます。
  • 設定を初めの状態に戻したいときは、Ultima7_JP フォルダの中の exult.cfg を、zip の中のものに入れ替えてください。
