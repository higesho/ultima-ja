日本語化プロジェクト

Ultima Underworld II: Labyrinth of Worlds

ウルティマ アンダーワールドII 日本語化パッチ

GOG.com 版の「Ultima Underworld 1+2」の第2作（DOS 版）を日本語で遊べるようにする、非公式のファンメイドパッチです。 オープニングの字幕、キャラクター作成、ブリタニアの人々や異世界の住人との会話、物の名前、巻物に出るメッセージ、本や巻物まで、ゲームの中の文章を日本語にしています。 ゲームのファイルは書き換えません。

ダウンロード（GitHub）

どんなゲーム？

ウルティマ アンダーワールドIIは、1993年に発表された「ウルティマ アンダーワールド」の続編です。 前作と同じく一人称の 3D で歩き回るダンジョン RPG で、舞台はひとつの迷宮から、いくつもの世界へと広がりました。

ガーディアンを打ち破ってから一年。その記念の宴の夜、ブリティッシュ城はまるごと黒い岩「ブラックロック」の殻に閉じ込められてしまいます。 外との行き来を断たれた城の地下で、アバタールは不思議な宝石を見つけます。 宝石を通ってガーディアンの手に落ちた異世界をめぐり、城を解き放つ手立てを探す旅が始まります。

城に閉じ込められた人々との暮らし、異世界ごとに違う住人や謎、ルーン石の魔法など、前作よりもさらに広い世界を味わうゲームです。

入れ方

  1. ダウンロードした UltimaUnderworld2_JP.zip を展開します。
  2. 出てきた ウルティマアンダーワールド2日本語化パッチ フォルダの中の UW2JP.COM・UW2JP.DAT・dosboxULTIMA2_single.conf を、ゲームのフォルダ（game.gog がある所）にコピーします。dosboxULTIMA2_single.conf は上書きしてください。
  3. DOSBOX フォルダも、ゲームのフォルダの中の DOSBOX フォルダにコピーします（opengl32.dll と ultima_ja.ini が増えます）。
  4. いつもどおり GOG Galaxy やショートカットから起動し、最初の画面（Ultima Underworld 2 Launcher）で 1 を押します。

GOG.com の「Ultima Underworld 1+2」の第2作で使えます。ゲームのファイルは書き換えないので、外せば英語版に戻ります。

外し方

  • ゲームのフォルダの UW2JP.COM と UW2JP.DAT を消し、GOG Galaxy の「ファイルの検証/修復」で dosboxULTIMA2_single.conf を元に戻します。
  • DOSBOX フォルダに増えた opengl32.dll と ultima_ja.ini も消します。
  • セーブデータは英語版と共通です。日本語版と英語版を行き来して遊べます。

字の形

  • 日本語の字は東雲フォント（12 ドット）で表示します。DOSBOX フォルダの ultima_ja.ini の font= を misaki に書き換えると、美咲フォント（8 ドット）になります。
  • 東雲フォントで描き直すのは、無地の背景に 1 色で書かれた字です。模様の上の字や、大きな字は、美咲フォントの形のまま表示します。
  • 起動設定で、画面をくっきり広げる表示（glshader=sharp）にしています。

遊ぶときの注意

  • 操作は英語版と同じです。キーの一覧はゲーム付属のマニュアルをご覧ください。
  • キャラクターの名前は英字で入力します。
  • 会話で言葉を入力する場面や合言葉は、謎解きのために英語のままのものがあります。
  • タイトルのメニュー、オプションのボタン、地図などの絵に描かれた字は英語のままです。
  • GOG Galaxy がゲームを更新・修復すると、dosboxULTIMA2_single.conf が元に戻ることがあります。そのときはもう一度上書きしてください。
