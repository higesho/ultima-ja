Ultima III: Exodus

ウルティマIII 日本語化パッチ

GOG.com 版の「Ultima 3」（DOS 版）を日本語で遊べるようにする、非公式のファンメイドパッチです。 タイトルやキャラクター作成から、地上・町・城・ダンジョンの冒険、店でのやりとり、戦闘、町の人々の会話、エンディングまで、ゲームの中の文章を日本語にしています。 ゲームのフォルダにファイルを置くだけで日本語になり、外せば英語に戻ります。

ダウンロード（GitHub）

GOG 版や Steam 版のゲームを読み込んで遊ぶ、新しい移植版の Windows アプリ（日本語対応）もあります。下の「新しい移植版（Windows アプリ）」をご覧ください。

どんなゲーム？

ウルティマIII は、1983年に発表されたウルティマ シリーズの第3作です。

魔術師モンデインと魔女ミナックスが倒されてから二十年。ソサリアの海に火山島が現れ、そこから謎の存在「エクソダス」の手先である怪物たちがあふれ出しました。 プレイヤーは人間・エルフ・ドワーフなどの種族と、戦士・僧侶・魔術師・盗賊など11の職業から4人の仲間を作り、エクソダスを倒す方法を探します。

シリーズで初めて4人のパーティで冒険する作品で、戦闘は専用の画面で一人ずつ動かして戦います。 町での情報集めや買い物、立体的に描かれるダンジョンの探索、船での航海などを通して、カードやしるし、時の王（Time Lord）の謎を解いていきます。 GOG.com で販売されているのは DOS 版です。

画面

入れ方

  1. ダウンロードした Ultima3_JP.zip を展開します。
  2. 中の U3JP.COM と dosboxULTIMA3_single.conf を、ゲームのフォルダ（ULTIMA.COM があるフォルダ）にコピーします。dosboxULTIMA3_single.conf は上書きしてください。DOSBOX フォルダも、ゲームのフォルダの中の DOSBOX フォルダにコピーします（opengl32.dll と ultima_ja.ini が増えます）。
  3. いつもどおり GOG Galaxy やショートカットから起動します。

ゲームのファイルは書き換えません。

Steam 版でも同じ手順で使えます。Steam のライブラリで「ローカルファイルを閲覧」を選ぶと開くフォルダにコピーし、いつもどおり Steam から起動してください。

外し方

  • U3JP.COM を消し、GOG Galaxy の「ファイルの検証/修復」で dosboxULTIMA3_single.conf を元に戻します。
  • Steam 版では、Steam の「ゲームファイルの整合性を確認」で dosboxULTIMA3_single.conf を元に戻します。
  • DOSBOX フォルダに増えた opengl32.dll と ultima_ja.ini も消します。

セーブデータは英語版と共通です。日本語版と英語版を行き来しても、続きから遊べます。

窓と字の形

  • ゲームは窓で起動します。窓のふちをドラッグすると、大きさを自由に変えられます。最大化もでき、変えた大きさは次の起動でも使われます。Alt＋Enter で全画面に切り替えられます。
  • 日本語の字の形は、東雲フォント（12ドット）と美咲フォント（8ドット）から選べます。最初は東雲フォントで、ゲーム中に F11 キーを押すと切り替わります。
  • 設定は DOSBOX フォルダの ultima_ja.ini で変えられます。
  • Steam 版では、窓の表示と東雲フォントの動きを確かめていません。

遊ぶときの注意

  • コマンドは原作どおり英字のキーで操作します（A＝攻撃、E＝入る、T＝話す・取引 など）。キーの一覧はゲームに付いているマニュアルをご覧ください。
  • メニューの選択肢には、押すキーを「R)」「J)」のように添えています。
  • キャラクターの名前は英字で入力します。
  • 「Exodus」「Ultima III」のロゴやタイトルのアニメーション、町の看板（WEAPON など）は文字ではなく絵なので、英語のままです。右側のパーティ欄の略号（M: L: H: F:）も英語のままです。
  • GOG Galaxy がゲームを更新・修復すると、dosboxULTIMA3_single.conf が元に戻ることがあります。そのときはもう一度上書きしてください。

新しい移植版（Windows アプリ）

LairWare の Macintosh 版をもとに作り直された移植版（synthwave-pixel 作、MIT ライセンス）を、日本語でも遊べるようにした Windows 用のアプリです。 お持ちの GOG 版か Steam 版の「Ultima 3」のファイルを読み込んで遊びます（アプリにはゲームのデータは入っていません）。地図の自動記録や冒険の記録、コントローラーでの操作など、現代向けの機能があります。原作どおりの遊び方や、DOS 版の見た目に切り替えることもできます。

ダウンロード（GitHub）

入れ方

  1. ダウンロードした Ultima3_App_JP.zip を展開します。
  2. 中のファイル（Ultima3JP.exe、LICENSE.txt、はじめにお読みください.txt）を、ゲームのフォルダ（EXODUS.BIN があるフォルダ）にコピーします。Steam 版は、Steam のライブラリで「ローカルファイルを閲覧」を選ぶと開くフォルダです。
  3. Ultima3JP.exe を起動します。「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します（署名のないアプリのため出る表示です）。

ゲームのファイルは書き換えません。GOG Galaxy や Steam から起動する DOS 版は、これまでどおり遊べます。

Ultima3JP.exe をほかの場所に置いた場合も、GOG Galaxy や Steam で入れたゲームなら自動で見つけます。見つからないときは「ゲームのフォルダを選ぶ」と出るので、EXODUS.BIN があるフォルダを選んでください。

外し方

  • Ultima3JP.exe、LICENSE.txt、はじめにお読みください.txt と、横にできる「Ultima III Data」フォルダ（セーブと設定）を消します。

遊び方

  • Windows が日本語なら、最初から日本語で始まります。英語で始まったときは、タイトルの「Settings」で「Language/言語」を選ぶと日本語に切り替わります。
  • 見た目は、設定の「絵柄」で今風の絵柄（Standard）と DOS 版の絵柄（PC CGA）を切り替えられます。日本語は Standard では東雲フォント（16ドット）で、PC CGA では美咲フォント（8ドット）で表示します。
  • 町の人の言葉や店の文などは、DOS 版の文を日本語にして表示します。
  • 音楽はありません。効果音は鳴ります。
  • F11 か Alt＋Enter で全画面と窓を切り替えます。Esc でポーズ メニューが開き、設定・手引き・ヘルプが見られます。
  • ゲームは町・城・ダンジョンの入口で自動でセーブされます（DOS 版のセーブとは別です）。タイトルの「ゲームを 書き出す／読みこむ」で、セーブをファイルに写せます。
  • 新しい版が出ると、タイトルのメニューに「更新」が出ます。
  • 合言葉（SEARCH、PRAY など）は、原作どおり英字で入力します。
