Ultima VII Part Two: Serpent Isle ＋ The Silver Seed

ウルティマVII 第2部 サーペントアイル 日本語化パッチ

GOG.com 版の「Ultima VII Part Two: Serpent Isle」（拡張シナリオ「The Silver Seed」入り）を日本語で遊べるようにする、非公式のファンメイドパッチです。 ウルティマVII を今の Windows で遊ぶためのエンジン「Exult」に日本語の表示を加え、オープニングとエンディングの字幕から、サーペントアイルの人々との会話、本や手紙、物の名前、ゲームのメニューまで、ゲームの中の文章を日本語にしています。 フォルダをひとつゲームのフォルダに入れるだけで遊べて、消せば元どおりです。

ダウンロード（GitHub）

どんなゲーム？

サーペントアイルは、1993年に発表されたウルティマVII の第2部です。

ブラックゲートが破壊されてから十八か月。ガーディアンの新たな企みを追って、アバターはイオロ、シャミノ、デュプレとともに、大蛇の柱のあいだを抜けて未知の地サーペントアイルへ渡ります。 騎士の町モニター、美を尊ぶ町フォーン、魔術師の都ムーンシェイド。それぞれに違う信条を持つ人々の間で、行方の知れない仲間を探し、この地に眠る古い蛇の文明と「均衡」の秘密に迫っていきます。

前作と同じく、町の人々はそれぞれの暮らしを送っていて、世界の中のほとんどの物に触れられます。 「The Silver Seed」は、ゲームの途中から遊べる拡張シナリオです。

入れ方

  1. ダウンロードした SerpentIsle_JP.zip を展開します。
  2. 出てきた SerpentIsle_JP フォルダを、フォルダごとサーペントアイルのゲームのフォルダ（SERPENT.COM と STATIC フォルダがあるフォルダ）に入れます。
  3. SerpentIsle_JP フォルダの中の SerpentIsle_JP.bat をダブルクリックすると始まります。

GOG.com の「Ultima 7 Complete」の Serpent Isle で使えます。The Silver Seed 入りとして起動します。 ゲームのファイルは書き換えません。設定とセーブデータは SerpentIsle_JP フォルダの中に作られます。

効果音を鳴らすには

音楽と声は、そのままで鳴ります。効果音は Exult では別に配られているので、鳴らしたいときは次のようにして入れてください。

  1. Exult のサイトのダウンロードのページ（https://exult.info/download.html）を開きます。
  2. 「Single Audio Data packs」の欄にある「Sound pack for Serpent Isle」（jmsfxsi.zip）をダウンロードします。Roland MT-32 の音が好みなら「Sound pack for Serpent Isle (Roland MT-32)」（sqsfxsi.zip）を選びます。両方入れてもかまいません。
  3. ダウンロードした zip の中身を、SerpentIsle_JP フォルダの中の data フォルダに展開します。
  4. 次に起動したときから効果音が鳴ります。両方入れたときは Roland MT-32 の音が使われ、ESC キーで出るメニューの「音の設定」で切り替えられます。

同じページの「All-In-One Audio Data packs」（exult_audio.zip）には、効果音のほかに音楽を録音したものも入っています。こちらを入れるときも、中身を data フォルダに展開します。

外し方

  • SerpentIsle_JP フォルダを消します。
  • セーブデータ（SerpentIsle_JP\save）も一緒に消えるので、残したいときは先に別の場所へ写してください。

遊ぶときの注意

  • GOG Galaxy やいつものショートカットから起動する DOS 版は英語のままです。日本語で遊ぶときは SerpentIsle_JP.bat から起動してください。
  • セーブデータは DOS 版とは別です。
  • 会話は、画面に出る話題をマウスで選んで進めます。ESC キーで会話を終えます。
  • 声のある場面には日本語の字幕が出ます。
  • 主人公の名前は英字で入力します。
  • 呪文の唱え言葉は、原作の言葉をローマ字で表示します。
  • 町の看板（ルーン文字や蛇の文字）は、原作どおりの文字のままです。
  • タイトルのロゴや、絵の中に描かれている英字は英語のままです。
  • Alt＋Enter で全画面と窓を切り替えられます。そのほかの設定は、ESC キーで出るメニューから変えられます。
  • 設定を初めの状態に戻したいときは、SerpentIsle_JP フォルダの中の exult.cfg を、zip の中のものに入れ替えてください。
