Ultima VI: The False Prophet

ウルティマVI 日本語化パッチ

GOG.com 版と Steam 版の「Ultima VI: The False Prophet」（DOS 版）を日本語で遊べるようにする、非公式のファンメイドパッチです。 物語の導入、ジプシーの問いかけによるキャラクター作成から、すべての人物との会話、物の名前、本や看板、戦闘のメッセージ、エンディングまで、ゲームの中の文章を日本語にしています。 ゲームのフォルダにファイルを置くだけで日本語になり、外せば英語に戻ります。

ダウンロード（GitHub）

どんなゲーム？

ウルティマVI は、1990年に発表されたウルティマ シリーズの第6作です。

ブラックソーンの圧政からブリタニアを救って数年。赤いムーンゲートに導かれてふたたびブリタニアに降り立ったアバタールを待っていたのは、ガーゴイルの軍勢でした。 徳の祠はガーゴイルに奪われ、人々はおびえて暮らしています。 ロード・ブリティッシュの頼みを受けたアバタールは、仲間とともに祠を取り戻す旅に出ますが、やがてガーゴイルたちがアバタールを「偽りの予言者」と呼ぶわけを知ることになります。

ひとつながりの広い世界を歩き回り、町の人々と話し、身の回りの物を手に取って使いながら進めるゲームです。 GOG.com と Steam で販売されているのは DOS 版です。

入れ方

  1. ダウンロードした Ultima6_JP.zip を展開します。
  2. 中のファイル（U6JP.COM、U6JP.DAT、U6JPMK.COM、U6JPMK.DAT、LOOK.JZD、dosboxULTIMA6_single.conf）を、すべてゲームのフォルダ（ULTIMA6.EXE があるフォルダ）にコピーします。dosboxULTIMA6_single.conf は上書きしてください。
  3. いつもどおり GOG Galaxy や Steam、ショートカットから起動し、最初の画面（Ultima VI Launcher）で 1 を押します。

Steam 版でも同じ手順で使えます。Steam のライブラリで「ローカルファイルを閲覧」を選ぶと開くフォルダにコピーしてください。

起動すると、最初に会話と本の日本語版のファイル（CONVERSE.JA、CONVERSE.JB、BOOK.JDT）が作られます。画面に「U6JPMK: CONVERSE.JA ok」などと一瞬表示されるのがそれです。 作られたファイルは、GOG 版ではゲームのフォルダの中の cloud_saves フォルダに、Steam 版ではゲームのフォルダに置かれます。

ゲームのファイルは書き換えません。

外し方

  • U6JP.COM、U6JP.DAT、U6JPMK.COM、U6JPMK.DAT、LOOK.JZD と、作られた CONVERSE.JA・CONVERSE.JB・BOOK.JDT を消し、GOG Galaxy の「ファイルの検証/修復」で dosboxULTIMA6_single.conf を元に戻します。GOG 版では、作られたファイルは cloud_saves フォルダにあります。
  • Steam 版では、Steam の「ゲームファイルの整合性を確認」で dosboxULTIMA6_single.conf を元に戻します。

セーブデータは英語版と共通です。日本語版と英語版を行き来しても、続きから遊べます。

人物との会話

会話では、言葉をローマ字で打ちます。英語の言葉（name、job など）もそのまま使えます。

打つ言葉意味
namae名前を聞く
shigoto仕事を聞く
sayounara話を終える（bye でも可。何も打たずに Enter でも終わります）
nakama / wakare仲間に誘う / 仲間から外す
kau / uru買う / 売る
hai / iieはい / いいえ

会話の中で色が変わっている言葉を打つと、新しい話が聞けます。ヘボン式（shi、chi、tsu）でも訓令式（si、ti、tu）でもかまいません。伸ばす音は省いても通じます（「ぼうけん」は bouken でも boken でも可）。言葉は 9 文字まで打てます。

遊ぶときの注意

  • コマンドは原作どおり英字のキーやアイコンで操作します。キーの一覧はゲームに付いているマニュアルをご覧ください。
  • キャラクターの名前は英字で入力します。仲間の名前も英字のまま表示されます。
  • 本・看板・墓碑のルーン文字の部分は、原作どおりルーン文字のまま表示します。
  • タイトルのロゴやメニュー、絵の中の文字は英語のままです。
  • GOG Galaxy や Steam がゲームを更新・修復すると、dosboxULTIMA6_single.conf が元に戻ることがあります。そのときはもう一度上書きしてください。
