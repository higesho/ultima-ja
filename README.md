# ウルティマ シリーズ 日本語化プロジェクト

ウルティマ（Ultima）シリーズを日本語で遊べるようにする、非公式のファンメイド日本語化プロジェクトです。
GOG.com で販売されている版を対象に、I から VIII までを順に日本語化していきます。
開発元・販売元とは関係ありません。

- サイト（作品の紹介・入れ方）: https://higesho.github.io/ultima-ja/
- ダウンロード: [リリース](https://github.com/higesho/ultima-ja/releases)
